# Dataset provenance and licenses

Dataset licenses are independent from the source-code licensing status of this repository.

## Parkinsons Telemonitoring

- **Used by:** Labs 02 and 03
- **Repository files:** `02_parkinson_regression/data/parkinsons_updrs.csv` and `03_parkinson_knn_regression/data/parkinsons_updrs.csv`
- **Upstream source:** [UCI Machine Learning Repository, dataset 189](https://archive.ics.uci.edu/dataset/189/parkinson)
- **DOI:** [10.24432/C5ZS3N](https://doi.org/10.24432/C5ZS3N)
- **Creators:** Athanasios Tsanas and Max Little
- **License:** [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The repository copy contains 990 derived observations from 42 subjects, while the upstream dataset contains 5,875 recordings. The transformation that produced this course subset was not recorded in the original repository and should be documented if that information becomes available.

Suggested citation:

> Tsanas, A. & Little, M. (2009). Parkinsons Telemonitoring [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5ZS3N
